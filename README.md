# 🎓 بوابة وقاعدة بيانات منح الماجستير والدكتوراه | Master's & PhD Scholarships Hub

موسوعة وقاعدة بيانات تفاعلية وشاملة تضم أكثر من **148 منحة ومنظمة دولية وإقليمية** لدعم طلاب الدراسات العليا (ماجستير ودكتوراه)، مع تركيز خاص على المنظمات الداعمة لطلاب **مصر والدول النامية والقارة الأفريقية** ومجالات **التكنولوجيا الحيوية والعلوم الطبية والهندسة الحيوية (Biotechnology & Life Sciences)**.

---

## 🌟 الميزات الرئيسية
- 📊 **قاعدة بيانات شاملة (148 فرصة):** تغطي المنح الحكومية العالمية (إيراسموس موندوس، ماري كوري، تشيفنينج، فولبرايت، داد، ميكست، منحة المجر، وتركيا)، منظمات التنمية (البنك الإسلامي للتنمية IsDB، مؤسسة ماستركارد، البنك الدولي)، وزمالات المراكز البحثية (ICGEB, EMBO, Wellcome Trust, KAUST).
- 💻 **بوابة ويب تفاعلية وقابلة للتعديل (`index.html`):** تتيح البحث الفوري المباشر، الفلترة حسب المرحلة الدراسية ونوع التمويل والتصنيف، مع إمكانية تعديل أي خلية وحفظ التغييرات تلقائياً في المتصفح، بالإضافة لزر إضافة منح جديدة وتصدير ملف Excel بضغطة زر.
- 📑 **ملف إكسيل منسق واحترافي (`Scholarships_Master_PhD_Radwa_Complete.xlsx`):** يضم روابط التقديم الرسمية المباشرة، الشروط والمؤهلات المطلوبة، مواعيد فتح التقديم والمواعيد النهائية (Deadlines)، ونوع التمويل.

## 📂 محتويات المستودع
| الملف | الوصف |
| :--- | :--- |
| **`index.html`** | البوابة التفاعلية المباشرة (تعمل على أي متصفح هاتف أو كمبيوتر بدون برامج) |
| **`Scholarships_Master_PhD_Radwa_Interactive.html`** | نسخة البوابة التفاعلية الكاملة |
| **`Scholarships_Master_PhD_Radwa_Complete.xlsx`** | ملف الإكسيل الشامل المنسق والمبوب لجميع الـ 148 منحة |
| **`curated_scholarships.json`** | البيانات المنظمة بصيغة JSON قابلة لإعادة الاستخدام والربط البرمجي |

## 🚀 كيفية الاستخدام
1. **فتح البوابة التفاعلية مباشرة:** افتح ملف `index.html` في أي متصفح ويب.
2. **البحث والفلترة:** استخدم شريط البحث للعثور على المنح الخاصة بتخصصك أو دولتك أو مواعيد التقديم.
3. **التعديل والإضافة:** يمكنك تعديل أي خانة مباشرة أو إضافة منحة جديدة وحفظها.
4. **التصدير:** اضغط على زر **تصدير إلى Excel** لتحميل نسخة محدثة فوراً.
