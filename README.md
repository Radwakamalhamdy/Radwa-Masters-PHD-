# 🎓 بوابة وقاعدة بيانات منح الماجستير والدكتوراه ومطابقة الـ CV | Master's & PhD Scholarships & CV Match Hub

موسوعة وقاعدة بيانات تفاعلية وشاملة تضم أكثر من **148 منحة ومنظمة دولية وإقليمية** لدعم طلاب الدراسات العليا (ماجستير ودكتوراه)، مع تركيز خاص على المنظمات الداعمة لطلاب **مصر والدول النامية والقارة الأفريقية** ومجالات **التكنولوجيا الحيوية والعلوم الطبية وهندسة العمليات الحيوية والذكاء الاصطناعي (Biotechnology & AI)**.

---

## 🌟 الميزات الرئيسية الجديدة

- 📊 **قاعدة بيانات شاملة (148 فرصة):** تغطي المنح الحكومية العالمية (إيراسموس موندوس، ماري كوري، تشيفنينج، فولبرايت، داد، ميكست، منحة المجر، وتركيا)، منظمات التنمية (البنك الإسلامي للتنمية IsDB، مؤسسة ماستركارد، البنك الدولي)، وزمالات المراكز البحثية (ICGEB, EMBO, Wellcome Trust, KAUST)، ووظائف الدكتوراه الممولة.
- 📋 **متطلبات تفصيلية لكل منحة:** تشمل بدقة (المؤهل والمعدل الأكاديمي، شهادات اللغة الإنجليزية والدرجة المطلوبة مثل IELTS/TOEFL، المستندات والمقترح البحثي، والشروط الخاصة مثل إيجاد مشرف أو خبرة العمل).
- ⚖️ **طرح الـ CV الخاص برضوى كمال من متطلبات المنحة (CV Gap Analysis):** تحليل مقارن مخصص يوضح:
  1. **ما يستوفيه ملفك بالفعل (محقق بالكامل):** المعدل المرتفع (3.53 MSA / 3.6 جرينتش بريطانيا First Class Honours)، الورقة البحثية المحكمة و10 بوسترات دولية، تأسيس الشركات الناشئة، وتوصيات الأساتذة المعتمدين.
  2. **المتبقي لاستيفاء الشروط 100%:** النواقص المحددة وخطوات العمل التنفيذية (امتحان اللغة، صياغة المقترح البحثي، التقديم على الجامعة الشريكة، أو مراسلة المشرف).
- 🎯 **نسبة الجاهزية والتوافق (Match Rate):** بادجات ملونة وتصنيف للجاهزية (جاهزية فائقة 95%+ تقديم فوري / مؤهلة بقوة 90%+ بانتظار الآيلتس / مؤهلة 85%+ تتطلب مقترح).
- 💻 **بوابة ويب تفاعلية وقابلة للتعديل (`index.html`):** تتيح البحث الفوري المباشر، الفلترة حسب نسبة التوافق، نوع التمويل والتصنيف، مع إمكانية تعديل أي خلية وحفظ التغييرات تلقائياً في المتصفح، وعرض بطاقة التفاصيل الشاملة في نافذة منبثقة، وتصدير ملف Excel بضغطة زر.
- 📑 **ملف إكسيل منسق واحترافي (`Scholarships_Master_PhD_Radwa_Complete.xlsx`):** يضم الأعمدة الجديدة الخاصة بالمتطلبات التفصيلية وطرح الـ CV ونسب التوافق.

## 🚀 كيفية الاستخدام
1. **فتح البوابة التفاعلية مباشرة:** افتحي ملف `index.html` في أي متصفح ويب.
2. **استعراض المنح المتوافقة:** استخدمي فلتر **نسبة التوافق مع ملفك** لاختيار المنح ذات الجاهزية الفائقة (95%+).
3. **الاطلاع على النواقص:** في كل صف ستجدين صندوقاً يوضح ما تملكينه حالياً وما ينقصكِ بدقة لاستيفاء الشروط.
4. **التعديل والإضافة:** يمكنكِ تعديل أي خانة مباشرة أو إضافة منحة جديدة وحفظها.
5. **التصدير:** اضغطي على زر **تصدير إلى Excel** لتحميل نسخة محدثة فوراً شاملة تحليلات الـ CV.
